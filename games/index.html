这里收录了我做的几个小游戏，网页版点开即玩，也可以下载源码自己跑。

⚠️ 网页版先说清楚

  • 首次加载极慢：每个 Godot 游戏都要先下载约 40MB 引擎文件（wasm），国内网络可能要等十几秒到几分钟，之后就快了（浏览器有缓存）
  • 可能会卡：FPS Arena 卡顿最明显，坦克竞技场次之，破山河相对流畅——网页版只有 WebGL 2.0，画质和帧率都比桌面版低
  • 想流畅玩就下载源码：解压后用 Godot 4.7 打开按 F5，就是完整桌面版体验
下面每张卡片都有「下载源码」按钮，可选 GitHub 或图床两个下载源。
⚔️
